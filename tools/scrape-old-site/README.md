# ย้ายข้อมูลจากเว็บไซต์เดิม (www.orst.go.th)

สคริปต์ดึงข่าว ประกาศ เอกสาร รูป และข้อความจากเว็บเดิม แล้วเขียนเป็นไฟล์เนื้อหา `content/pages/*.json`
ใช้ระหว่างที่เว็บเดิมยังเปิดอยู่ เพื่อดึงข้อมูลล่าสุดซ้ำได้ก่อนย้ายเข้า CMS จริง

**ไม่ใช่ส่วนหนึ่งของเว็บ** — ไม่ถูกโหลดและไม่ถูก build (เว็บยังไม่มี dependency ตามกฎใน CLAUDE.md)
ต้องมี Python 3.10+ และ Pillow (`pip install pillow`)

```bash
python tools/scrape-old-site/migrate.py
```

```bash
node tools/validate.mjs
```

- หน้าเว็บเดิมที่โหลดแล้วเก็บใน `cache/` (ไม่อยู่ใน git) — ลบโฟลเดอร์นี้ถ้าต้องการข้อมูลล่าสุด
- สคริปต์**เขียนทับ**ไฟล์ JSON ของหน้าที่มันสร้างทั้งไฟล์ — ถ้าแก้หน้าเหล่านั้นด้วยมือแล้ว ให้ดู `git diff` ก่อน commit
- ที่มาของแต่ละหน้าอยู่ในฟิลด์ `_note` ของไฟล์ JSON
- ลำดับขั้นและหน้าที่แต่ละขั้นสร้าง ดูหัวไฟล์ `migrate.py`
