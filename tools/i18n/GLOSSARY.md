## กฎการแปล

1. ภาษาอังกฤษแบบทางการของหน่วยงานรัฐ กระชับ อ่านง่าย (ไม่ใช่การแปลคำต่อคำ)
2. ตัวเลขไทย → เลขอารบิก · ปี พ.ศ. → ค.ศ. (ลบ 543) เช่น "พ.ศ. ๒๕๖๙" → "2026", "ปีงบประมาณ 2569" → "fiscal year 2026"
   ยกเว้นชื่อเฉพาะที่มีปี พ.ศ. เป็นส่วนหนึ่งของชื่อ (เช่น ชื่อพระราชบัญญัติ) ให้ใช้ "B.E. 2550"
3. ชื่อบุคคล: ถอดเป็นอักษรโรมันตามหลักราชบัณฑิตยสภา (RTGS) · คำนำหน้า นาย/นาง/นางสาว → Mr./Mrs./Ms. ·
   ศาสตราจารย์ → Professor · รองศาสตราจารย์ → Associate Professor · ผู้ช่วยศาสตราจารย์ → Assistant Professor · ดร. → Dr.
4. ชื่อบริษัท/ร้าน/ห้างหุ้นส่วนเอกชน: ถอดเป็นอักษรโรมัน + Co., Ltd. / Ltd. Part. / Shop
5. **เนื้อหาที่อธิบายภาษาไทยเอง** (หลักเกณฑ์ ลักษณนาม การอ่าน เครื่องหมาย คำที่มักเขียนผิด ราชาศัพท์ ฯลฯ):
   ตัวอย่างคำไทยต้องคงเป็นอักษรไทย แล้วอธิบายเป็นภาษาอังกฤษ ใส่คำอ่านโรมันหรือความหมายในวงเล็บเมื่อช่วยให้เข้าใจ
   เช่น "ลักษณนาม ของ ช้าง ใช้ เชือก" → "Classifier for ช้าง (elephant): เชือก (chueak)"
   ถ้าข้อความทั้งช่องเป็นคำไทยตัวอย่างล้วน (เช่น ช่องตาราง "สิบ-เอ็ด") ให้คงไว้ตามเดิมพร้อมคำอ่าน: "สิบ-เอ็ด (sip-et)"
6. ข้อความในวงเล็บเหลี่ยม [ ... ] คือ placeholder รอข้อมูลจริง — แปลข้อความข้างใน คงวงเล็บไว้
7. ห้ามเพิ่มข้อมูลที่ไม่มีในต้นฉบับ ห้ามตัดข้อมูล (ตัวเลข วันที่ ชื่อ จำนวนเงิน)
8. ข้อความสั้นที่เป็นปุ่ม/ป้าย ใช้ Title case หรือ Sentence case ตามความเหมาะสม เช่น "ดูทั้งหมด" → "View all"
